# EnglishDictionary
This is  a  simple  english dictiionary made in c++ .

This uses Damerau Levenshtein distance as main algorithm .
The Damerau-Levenshtein distance measures how different two text strings are by counting the least number of single-character edits—insertions, deletions, substitutions, or transpositions of adjacent characters—needed to change one string into the other

# How to Run the program 
There is a cmake script which lets it run anywhere 

cmake -B build
cmake --build build
./build/autocorrect
